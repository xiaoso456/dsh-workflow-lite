# HTTP `http`

定义里只写 `{ "kind": "http" }`。地址和令牌是本机设置：

- 地址是 `http://<主机>:<端口>/trigger/<hook>`，`hook` 缺省用工作流名；端口缺省 3791，在插件设置里改。
- 缺省只接受本机的请求；要让别的机器调用，由用户在插件设置里把监听地址改成 `0.0.0.0` 或本机网卡地址。外网的服务（GitHub.com 之类）还要用户自己配隧道或转发。
- 令牌放在 `Authorization: Bearer <令牌>` 请求头里，或地址后面的 `?token=<令牌>`；`local.noToken: true` 不校验令牌（只在用户明说时用）。
- 只收 `POST`，请求体最大 1 MiB，原样作为背景信息；收到就回 202，不等工作流跑完。令牌不对 401，卡片关着或地址不对 404。
- 请求头不进背景信息。要按请求头判断（事件类型、签名），改用监视程序自己开端口（见 `examples/github.md`）。

`write_trigger` 可以带 `local.hook`、`local.token` 设地址和令牌（令牌 16 到 256 位，只用字母、数字和 `- _ . ~`）；`read` 这张卡片能读到完整地址和令牌，用户要配到别的系统时可以直接给他。
