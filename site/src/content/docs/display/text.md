JSON、代码、配置这类文本放进卡片后保持原样，等宽显示、不折行。

![JSON 卡：压成一行的内容自动展开缩进](../../../assets/shots/card-json.webp)

## JSON

压成一行的 JSON 会自动展开并缩进。在查看框里可以在「格式化」和「源码」之间切换，看原文用「源码」。

![JSON 查看框：「格式化」与「源码」可切换](../../../assets/shots/viewer-json.webp)

## 其他文本

- 「缩放」调整字号。
- 文件超过上限时只显示文件大小，可用其他程序打开。
- 支持 GBK、带 BOM、UTF-16 编码的文件。
