让步骤把结果写成一个 HTML 文件，画布上就多了一块随执行刷新的看板：当前轮次、结论、指标一眼可见。

![HTML 看板卡：跟随画布配色，贴在画布上](../../../assets/shots/card-web.webp)

## 使用

1. 让步骤产出一个 HTML 文件，如 `dashboard.html`，每轮覆盖同一个文件。
2. 给这个文件建资源卡（从步骤拖线到空白处，选「产出文件」），打开「在画布上展示」。
3. 选「大」尺寸；页面太大时调小「缩放」，使整页可见。

完整的搭建过程见[用看板查看每轮产出](/dsh-workflow-lite/scenarios/dashboard/)。

## 显示方式

- 网页按「宽 × 高」排版，再整张等比缩放；卡片的大小是「大小 × 缩放」。
- 看板会跟着画布的配色主题变色，和卡片融成一块；外观可选卡片、柔边镂空、纯镂空、毛玻璃。
- 卡片里显示一屏摘要；点开查看框，或用其他程序在浏览器里打开，显示完整内容。
- 「让模型适配展示」开启时，写看板的步骤知道卡片多大，按卡片宽度排版，排满一屏。

## 注意

- 网页里按相对路径引用的图片、样式暂时显示不出来，查看框标题行会提示有几张没能显示；需要完整效果时，点击「用其他程序打开」。
- 点击「交互」后可在卡片里点击网页，Esc 退出。
- 每一轮的看板会存一版，可回看对比，见[各轮产出回看](/dsh-workflow-lite/display/rounds/)。
